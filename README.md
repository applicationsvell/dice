# 紅白ダイス

赤と白の3Dサイコロ2つ。画面をタップするとサイコロを振ります。画面に文字はありません。

- 画面のどこを押してもよく、**押した場所に近いほうのサイコロが負け**、もう一方が勝つ
- 負けさせたい色のサイコロの上か、その近くを押せばよい

サイコロは毎回ちがう場所に止まるので、押す場所も毎回変わります。引き分けは出ません。

## 遊ぶ

https://applicationsvell.github.io/dice/

### iPhoneのホーム画面に追加する

1. Safariで上のアドレスを開く
2. 「共有」→「ホーム画面に追加」
3. ホーム画面のアイコンから開くと、全画面のアプリとして動きます。一度開けば電波がなくても使えます。

## 開発メモ

- `src/kouhaku-dice.html`：本体（アーティファクト版と同じもの）。外部のライブラリは使わず、WebGLで直接描いています。
- `node src/build-app.js`：本体から `index.html`・`manifest.webmanifest`・`sw.js` を作り直す。
- `node src/icon.js`：ホーム画面のアイコンを作り直す（Playwrightが必要）。
- 更新したら、アプリを開き直すと新しい版になります（ページはネットにつながっていれば常に最新を取りにいきます）。
